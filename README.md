A small stupid mod for changing the players size (visually).

this idea came to me while playing some minecraft, and i decided, why not make it into a full blown mod.

(the mod allows any value from 0.25 up to 2.0 times size)

Contributions to code aswell as ideas are welcome! <3

_it is recommended to use [Mod Menu](https://modrinth.com/mod/modmenu) with this mod, to access the config! tho there are keybinds for: enable/disable, bigger, smaller._
